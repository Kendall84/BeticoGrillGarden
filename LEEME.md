# BETICO Grill Garden – sitio web

## Estructura
- `index.html` + `home.css` + `home.js` → página principal
- `menu.html` + `styles.css` + `app.js` + `menu-data.js` → menú digital (ES/EN)
- `assets/` → logos (`logo.png`, `logo-transparent.png`)
- `images/` → fotos de la página principal

## Cómo cambiar una foto del Top 5
Guardar la nueva foto en `images/` con el mismo nombre (JPG, ideal ~1400 px de ancho):
`gallo-lomo-aguja.jpg` (#1), `hamburguesa-betico.jpg` (#2), `tacos.jpg` (#3), `chicharrones.jpg` (#4), `arroz-wok.jpg` (#5).
Si falta alguna, la tarjeta muestra el logo.
